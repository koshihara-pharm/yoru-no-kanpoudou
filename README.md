# なつめ君の漢方占い（試作）

札に体のことを書くと、占い師のなつめ君が、書いていない体のことを言い当てにいくゲームの試作です。

遊ぶ: https://koshihara-pharm.github.io/yoru-no-kanpoudou/

- 体質を楽しく知るための試作品です。病気の判断や治療には使えません。体調が気になるときは、医師や薬剤師に相談してください。
- 遊ぶ人の答えは、どこにも送られず、保存もされません。
- 中身は作っている途中で、予告なく変わります。
- 絵は、AI の画像生成（OpenAI）で作りました。登場人物は架空です。
- 占い師の絵を動かす部品に、mesh-avatar（MIT ライセンス）を使っています。ライセンスの文は `lib/LICENSE.mesh-avatar.txt` にあります。
